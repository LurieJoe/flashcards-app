Before troubleshooting

  1. Open the app’s Import tab.
  2. Select Create Backup.
  3. Save the backup somewhere you can locate again.

The app shows an older version

  1. Connect the device to the internet and open the app.
  2. When the update notice appears, select Restart and update.
  3. If no notice appears, close the installed app, open the app URL in the browser, and try again.

The installed app will not open

  1. Open https://flashcardflurry.com/app/ directly in Safari or Chrome.
  2. If the browser version works, remove the old Home Screen icon only after confirming you have a current backup.
  3. Install the app again from the browser.

Decks appear to be missing

Confirm that you opened the same domain and browser used previously. Browser data is separated by website address and browser profile. If you changed devices, browsers, or domains, restore a full backup.

Import does not recognize a document

Scanned or image-only files require OCR before Flashcard Flurry can read their text. Convert the material to a text-based Word document, CSV, or plain-text list.

What to include when reporting a problem

  • Device model and operating-system version.
  • Browser name and whether you used the installed Home Screen app.
  • The Flashcard Flurry version shown at the bottom of Settings.
  • Steps that reproduce the issue and the result you expected.
  • A screenshot with private study content removed or obscured.

Do not attach a full backup or private deck to a public GitHub issue. Backups may contain every profile and card stored in the app.
